导入词库

从手机里选一个 .txt / .csv / .json 文件，完全离线解析。

每行一条，例如：abandon,v. 放弃，或 abandon /əˈbændən/ 放弃。

输入 txt/json 直链（需允许跨域，如 GitHub raw、jsDelivr），拉取后可离线保存。

格式：CSV/制表符/空格分隔均可；也支持 JSON 数组 [{"word":"…","phonetic":"…","translation":"…"}]。重复词会自动跳过，最多 5000 条。
